Scripts:
0) load_environmental_variables # gets .env variables 
1) download_data # download all relevant data from google drive or public
*2) preliminary_cost_estimation # preliminary machinery and ATP cost of E-rxns
*3) build_psim_recon2_2 # generates a PSIM of all relevant machinery for recon2.2
*4) build_psim_expression # script for PSIM of expression machinery specifically; also generates expression_module_model.json and required_metabolic_model_metabolites.txt
5) polyA_statistics # data and statistical models with polyA lengths
6) correct_inputs # ensures exchange of NTPs, NMPs, and aa's, and changes a few incorrect gene notations for human model, addes expression proteins to psim_me
7) utils # overlapping variables/functions used in proceeding scripts
8) gene_information.ipynb # class for compiling all necessary information of a gene for expressing it in a ME model
9) build_mrna_expression_reactions # creates all mrna expression reactions necessary for a given gene for the ME model 
10) build_trna_expression_reactions # all tRNA biogenesis reactions
11) utils_2 # overlapping variables/functions used in proceedng scripts that require scripts 6-8
12) build_protein_expression_reactions # protein translation, transport, and degradation
*13) test_expression_module # script to test that mrna_reactions and protein_reactions make sense for all combinations of cases
14) build_ribosome_biogenesis_reactions # all ribosome biogenesis reactions (rRNA synthesis, RP synthesis, complex formation)


Scripts are in order; * = not part of pipeline

Data Files
1) expression_module_psim.csv # fully filled PSIM for all expression module machinery
2) required_metabolic_model_metabolites.txt # list of all required metabolite ids from the input cobrapy model
3) expression_module_model.json # a cobrapy model containing all possible reactions of the expression module reactions

Inputs
1) data/processed/corrected_psim_me.csv # default input PSIM if there is not a user provided one<-will need to change this to root directory eventually
2) data/processed/corrected_model.json # default input CobraPy model if there is not a user provided one<-will need to change this to root directory eventually
